\title[Drug Label Dataset: Information Retrieval System and Evaluation]{%
  Drug Label Dataset: Information Retrieval System and Evaluation
}

\begin{abstract}
  This report presents the development of an information retrieval system for a comprehensive drug label dataset built from the OpenFDA API. The project encompasses the entire pipeline, from data preparation and characterization to the implementation and evaluation of a Solr-based search engine. The dataset integrates structured identifiers and unstructured text, supporting rich retrieval tasks. Two distinct retrieval setups were implemented and assessed through manual evaluation, demonstrating the system's effectiveness. The report concludes with an analysis of retrieval performance and outlines directions for future enhancements.
\end{abstract}
